# Assets

KingCordGx artwork used by the published theme lives in this directory.

- `kingcord-background.jpg` — purple liquid theme background
- `kingcord-discord-logo.jpeg` — neon galaxy artwork used for Discord's Home button

Suggested files:

- `preview.png` — main README preview
- `banner.png` — repository or release banner
- `icon.png` — square project icon

Optimize images before committing them and use relative links from the repository README so they work on GitHub and GitHub Pages.
